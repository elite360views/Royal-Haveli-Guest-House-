HOW TO PUT THIS ON GITHUB PAGES:
1. Create a new GitHub repository (for example: royal-haveli-guest-house).
2. Upload ALL files and the assets folder, keeping the same folder structure.
3. Open the repository Settings -> Pages.
4. Under Build and deployment, choose "Deploy from a branch".
5. Select the main branch and / (root), then Save.
6. GitHub will give you a website address ending in github.io.

The website is a static site, so no hosting server or database is required.
